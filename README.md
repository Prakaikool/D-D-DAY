# D-D-DAY - Daily Warm Message

A soft and cozy web experience inspired by fortune cookies created to share small, gentle words of encouragement every day.
Users can generate a random quote and view it inside a pastel overlay card.
Each message is designed to feel personal, warm, and comforting.

## Features

- Random quote generator (Thai + English)
- Overlay quote card with animated UI
- Daily logic to prevent repeating messages within the same day
- Share quote as an image
- Fully responsive design (mobile / tablet / desktop)
- Soft pastel UI with floating decorative elements
- Soft pastel UI with floating decorative elements

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React Hooks

## How It Works
1. The homepage shows a daily warm greeting.
2. The homepage shows a daily warm greeting.
3. Users press “Click here!” to generate a random quote.
4. Users can:
  - Close the card
  - Share the quote as an imag

## Responsive Design

This project is carefully optimized for:

- Mobile
- Tablet & Desktop

Special layout adjustments were made to prevent text overflow on smaller screens.

## Design Concept

The visual style focuses on:

- Soft pastel colors
- Friendly typography
- Calm emotional tone
- Fortune-cookie inspired storytelling

The goal is to create a small digital space that feels warm and personal.
